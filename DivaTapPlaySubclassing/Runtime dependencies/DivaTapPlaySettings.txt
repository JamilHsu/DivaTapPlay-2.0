The logic of the method for detecting sliding:
# The following pseudocode is for illustrative purposes only and does not represent the actual situation (actual code needs to consider issues such as positive and negative displacement).

Momentum = max(OldMomentum - over_time * momentum reduce_ratio , 0) # It will use the momentum reduce_ratio or the "momentum reduce_ratio in slider only area"
NewMomentum = √(Momentum^2 + Displacement) # The unit of Displacement is pixels. The value of Displacement depends primarily on the horizontal displacement distance, but the vertical displacement distance is also considered (with less weight).
if (NewMomentum <= 0):
    release slider button
else if (The slider button was not pressed and NewMomentum > slide_require):
    press slider button
# It will use the slide_require or the "slide_require in slider only area"

It's important to note that the sliding determination is based on a momentum system. This system adds the displacement distance to the momentum, but in a square root form. Specifically: NewMomentum = √(OldMomentum^2 + Displacement).

Therefore, `slide_require` is approximately a quadratic relationship. That is, setting `slide_require` to 2 times will actually increase the minimum required displacement by about 4 times. Since the higher the momentum, the slower the momentum accumulation, this also affects the speed required for sliding.

`momentum reduce_ratio` is the amount of momentum that decreases every 1µs(0.0000001 second). This affects how long after stopping the movement will the slide key be released. This also affects the minimum speed required to trigger a slide.
